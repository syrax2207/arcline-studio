# ARCLINE STUDIO — Design System

## Principles
1. Space
2. Grid
3. Typography
4. Material
5. Motion
6. Restraint

## Colors
Chalk #F1EEE7
Charcoal #171716
Warm Stone #D8D0C3
Deep Umber #302A25
Clay #A98F78
Muted Olive #747662

## Typography
Display: Instrument Serif
Interface: Inter
Utility: DM Mono

## Type Scale
Desktop starting ranges:
Display XL 96–120px
Display 72–96px
H1 56–72px
H2 48–64px
H3 32–40px
H4 24–30px
Body Large 20px
Body 16–18px
Body Small 14px
Utility 11–13px

Use fluid responsive sizing rather than rigid values where appropriate.

## Spacing
4, 8, 12, 16, 24, 32, 48, 64, 80, 96, 120, 160, 200px.

## Containers
Max width approximately 1440px.
Desktop side padding 48–64px.
Tablet 32–40px.
Mobile 20–24px.

## Grid
Desktop: 12-column architectural grid with generous margins and controlled gutters.

## Borders
Prefer subtle 1px borders. Use borders and tonal contrast rather than shadows.

## Radius
Default 0–4px. Maximum normal radius 8px.

## Shadows
Minimal. Avoid floating-card aesthetics.

## Buttons
Primary: DISCUSS YOUR SPACE →
Secondary: EXPLORE PROJECTS →
Use text + arrow + restrained line animation rather than pill buttons.

## Images
Hero: cinematic / 16:9 direction.
Feature: 3:2.
Editorial/detail: 4:5.
Material: 1:1.
Full-bleed: variable.

## Components
Primitives: Container, Section, Eyebrow, Heading, Text, ArrowLink, Button, Divider.
Interface: Navigation, Footer, MobileMenu, ProjectMeta, ImageReveal, MaterialSwatch, FormField.
Sections: Hero, Philosophy, Projects, Materiality, Principles, Services, Approach, Studio, Editorial, Contact.
Pages: Home, Projects, ProjectDetail, Studio, Services, Approach, Contact, NotFound.

## Responsive Principle
Do not merely shrink desktop. Recompose layouts for tablet and mobile.

## Accessibility
Semantic headings, keyboard navigation, visible focus, sufficient contrast, meaningful alt text, accessible forms and reduced-motion support.

## AI Guardrails
Do not invent colors, fonts, gradients, glassmorphism, excessive rounded cards, fake content or new visual patterns without approval.
