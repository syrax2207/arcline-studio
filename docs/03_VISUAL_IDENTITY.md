# ARCLINE STUDIO — Visual Identity

## Concept
Architectural Warmth.

The identity sits between cold technical minimalism and decorative luxury: precise architecture + tactile materials + human warmth.

## Color Palette
| Token | Hex | Role |
|---|---|---|
| Chalk | #F1EEE7 | Main background |
| Charcoal | #171716 | Primary dark |
| Warm Stone | #D8D0C3 | Secondary surfaces |
| Deep Umber | #302A25 | Warm dark surfaces |
| Clay | #A98F78 | Restrained accent |
| Muted Olive | #747662 | Secondary accent |

## Approximate Color Ratio
70% Chalk
15% Charcoal
8% Warm Stone
5% Deep Umber / Clay
2% Muted Olive

## Typography
### Display
Instrument Serif (or a close approved substitute if unavailable).

### Interface
Inter.

### Utility
DM Mono.

## Logo Direction
Typographic/custom architectural wordmark. Explore subtle ARC + LINE logic. Avoid house, building, furniture, leaf or generic monogram clichés.

## Graphic Language
- Thin rules
- Project numbering
- Technical metadata
- Architectural grid
- Negative space
- Editorial asymmetry

## UI Shape Language
Default radius 0–4px. Avoid large rounded cards and pill-shaped controls.

## Photography
Natural whites, believable materials, subtle warmth and controlled contrast. Intentional cropping is part of the identity.
