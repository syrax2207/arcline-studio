# ARCLINE STUDIO — UX Architecture

## Primary Website Goal
Turn visitor interest into a qualified design enquiry.

## UX Hierarchy
Build desire → demonstrate design capability → build trust → explain approach → make enquiry easy.

## Ideal Journey
LAND → understand ARCLINE in about 5 seconds → see work → explore projects → understand thinking → services/process → trust → imagine own project → DISCUSS YOUR SPACE.

## Core UX Principle
Show → Explain → Prove → Reassure → Invite.

## Navigation
Projects / Studio / Approach / Contact
Persistent CTA: Discuss Your Space →

## Homepage Sections
1. Hero — The Arrival
2. Studio Statement — The Philosophy
3. Selected Projects — The Proof
4. Materiality — The Tactile Moment
5. Design Principles — The Thinking
6. Services
7. Approach
8. Studio
9. Editorial Statement
10. Contact
11. Footer

## Project Detail
Project Hero → Overview → Design Idea → Full-scale image → Spatial details → Material palette → Design decisions → Image sequence → Project information → Next project.

## Services
Residential Interiors, Spatial Planning, Material Direction, Design Detailing.

## Approach
Understand → Define → Develop → Resolve.

## Contact Enquiry
1. What are you designing?
2. Where is the project?
3. Where are you in the process?
4. Tell us about the space.
5. Name, email and phone.

## Avoid
Fake testimonials, fake awards, fake statistics, aggressive popups, unnecessary chatbot, pricing page, giant blog navigation and unsupported execution/construction claims.
