# ARCLINE STUDIO — Test Plan

## Functional
- Navigation links work.
- Mobile menu opens/closes correctly.
- Project links route correctly.
- Dynamic project pages render correct data.
- Material interaction works.
- Principles interaction works.
- Service interaction works where supported.
- Contact form validation works.
- Success/error/loading states work.
- 404 route works.

## Responsive Matrix
### Mobile
375px / 390px / 430px

### Tablet
768px / 1024px

### Desktop
1280px / 1440px / 1920px

## Accessibility
- Keyboard navigation
- Visible focus
- Semantic headings
- Alt text
- Color contrast
- Form labels
- Error messaging
- Reduced motion
- Touch target sizing

## Performance
- Hero image optimized and prioritized
- Below-fold images lazy-loaded
- No unnecessary dependencies
- Font loading reviewed
- Animation performance checked
- Layout shifts minimized
- Mobile performance reviewed

## SEO
- Unique page titles
- Meta descriptions
- Canonicals
- H1 hierarchy
- Open Graph
- Sitemap
- Robots
- Structured data where appropriate
- Internal links
- No broken links

## Visual
- Colors match tokens
- Typography matches approved system
- Spacing follows scale
- Grid is consistent
- Project compositions feel editorial
- No accidental generic SaaS patterns

## Browser
Test current major Chrome, Edge, Firefox and Safari where available.

## QA Rule
A feature is complete only when it is visually correct, functional, responsive, accessible, performant and architecturally appropriate.
